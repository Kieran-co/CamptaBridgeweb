# Page bêta ComptaBridge

Page de présentation locale, prête à être relue avant publication.

## Confidentialité

- Les visuels n'utilisent aucun relevé réel.
- Le formulaire ne transmet actuellement aucune donnée.
- Avant publication, connecter le formulaire à une destination privée validée
  par le propriétaire de ComptaBridge.

## Publication

Ne pas publier avant validation :

1. de l'adresse ou du service privé qui recevra les candidatures ;
2. du nombre définitif de places ;
3. des banques annoncées comme compatibles ;
4. des mentions légales et de la politique de confidentialité.
